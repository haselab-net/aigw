aigw チュートリアル 基本編

日本語English简体中文
入口Docker で試す基本編発展編

スマホや PC のブラウザから、サーバー上の AI エージェント(Claude Code など)を使うための手引きです。基本編では、アカウントを作ってから、普段の AI コーディングができるようになるまでを説明します。サーバーごとに入っている機能が少し違うので、分からないところは管理者に確認してください。

aigw は https://<サーバー>/agents/ で開くチャット風の画面です。チャットに書いた指示は、サーバー上の自分専用のコンテナで動く Claude Code に届き、返事がチャットに戻ってきます。

フォルダ・巡回・通知・パスキー・ホストやルートのシェル・他のマシンなどは発展編にあります。

1. アカウントを作る

管理者が許可したドメインの Google アカウントがあれば、aigw の画面から自分でアカウントを作れます(この機能を有効にしているサーバーの場合)。そうでなければ管理者に作ってもらいます。

  1. ブラウザで https://<サーバー>/agents/ を開き、「Google でログイン」から許可されたドメインのアカウントを選びます。
  2. まだアカウントが無いと「アカウント作成」のフォームが出ます。ユーザー名を決めて送信します。
    • 使える文字は英小文字・数字・-・_。先頭は英小文字か _。32文字まで。
    • あとから自分では変えられません。
  3. 送信すると SSH の秘密鍵が1回だけ表示されます。画面を閉じる前に必ず保存してください。二度と表示されません。
  4. これで aigw が使えます。次回からは Google でログインするだけです。

SSH でも入れるようにする(パスキー登録に必要)

aigw だけを使うなら SSH は不要です。ただし、Email やホストのシェルに使うパスキーの登録には SSH ログインが1回要るので、早めに済ませておくと楽です。使っている PC に合わせて、どちらかの手順で行います。

サーバーによっては、SSH を組織の内側のネットワークからだけ受け付けています。その場合、外から SSH するときは、管理者が案内する方法で先に内側のネットワークに入ってください。aigw の画面(ブラウザ)は外からでもそのまま使えます。

Mac・Linux、Windows の MSYS2(Git Bash も同じ)

# 自分の PC で: もらった鍵を保存して権限を絞る
mkdir -p ~/.ssh
mv ~/Downloads/id_ed25519_<ユーザー名> ~/.ssh/
chmod 600 ~/.ssh/id_ed25519_<ユーザー名>

# 初回ログイン。ログイン直後にパスワードの設定を求められる
ssh -i ~/.ssh/id_ed25519_<ユーザー名> <ユーザー名>@<サーバー>

MSYS2 では ~ は MSYS2 のホーム(例: C:\msys64\home\<名前>)で、Windows のホーム(C:\Users\<名前>)とは別です。ダウンロードしたファイルは /c/Users/<Windowsの名前>/Downloads/ にあります。MSYS2 の ~/.ssh に置いた鍵は、PowerShell の ssh からは見えません。

Windows 標準の OpenSSH(PowerShell)

Windows 10/11 には ssh が入っています(無ければ「設定 → システム → オプション機能」で「OpenSSH クライアント」を追加)。PowerShell で次を実行します。chmod は使えないので、権限は icacls で絞ります。

# 鍵を C:\Users\<Windowsの名前>\.ssh\ へ移す
mkdir -Force $env:USERPROFILE\.ssh
Move-Item $env:USERPROFILE\Downloads\id_ed25519_<ユーザー名> $env:USERPROFILE\.ssh\
$key = "$env:USERPROFILE\.ssh\id_ed25519_<ユーザー名>"

# 自分以外が読めないようにする(継承を切り、自分だけに読み取りを許す)
icacls $key /inheritance:r
icacls $key /grant:r "$($env:USERNAME):(R)"

# 初回ログイン。ログイン直後にパスワードの設定を求められる
ssh -i $key <ユーザー名>@<サーバー>

「UNPROTECTED PRIVATE KEY FILE」「bad permissions」と言われたら、icacls の2行を実行し直してください。PowerShell では -i ~/.ssh/... の ~ が展開されないことがあるので、$env:USERPROFILE で書いています。

パスワードは、この初回ログインで決めるまで誰にも使えない状態になっています。2回目からは同じコマンドで入れます。

毎回 -i を書かないようにする

次の内容を設定ファイルに書くと、ssh aigw だけで入れます。設定ファイルは、Mac・Linux・MSYS2 では ~/.ssh/config、Windows 標準では C:\Users\<Windowsの名前>\.ssh\config(拡張子なし)です。IdentityFile の ~ はどちらでも ssh が自分のホームに読み替えます。

Host aigw
    HostName <サーバー>
    User <ユーザー名>
    IdentityFile ~/.ssh/id_ed25519_<ユーザー名>
管理者に作ってもらったアカウントで aigw にログインできないときは、SSH で入って aigw-set-email you@example.com を1回実行してください。そのメールアドレスの Google アカウントでログインできるようになります。

2. 画面の見方

aigw の画面は「セッション一覧」と「チャット」の2枚です。セッションとは、サーバー上で動き続ける1つの作業場所(Claude Code やシェル)のことです。

3. 普段の AI コーディングのしかた

普段は Claude を選んでセッションを作り、チャットで指示するだけです。Claude は自分専用のコンテナ(砂場)の中で、ファイルを作り、コマンドを実行します。

セッションを作る

  1. 作成欄の種類で Claude を選びます。
  2. 📁 の行で作業フォルダを選びます。最初は sandhome(コンテナの中のホーム)です。
    • 「サブフォルダを開く…」で1段ずつ下へ、↑ で上へ移動します。
    • ＋ で今いる場所に新しいフォルダを作れます。
  3. ⏱ の欄は普段は「新規」のまま。前の会話を続けたいときは、ここで選びます(下の「続きから」)。
  4. 「権限確認をスキップ」は普段はオンのままでかまいません。コンテナの中なので、Claude がファイルを書き換えても外には影響しません。
  5. 名前を付けて(任意)開始を押すとチャット画面になります。

指示を出す・結果を受け取る

  • 入力欄に日本語で書いて 実行。スマホのキーボードの改行キーも実行と同じです(入力欄の中で改行したいときは Shift+Enter)。
  • Claude が考えている間も、続けて指示を送れます。
  • 手元のファイルを渡す: 📎 で選ぶか、入力欄に貼り付けます。サーバー上に保存され、そのパスが入力欄に入るので、「このファイルを見て…」と続けて送ります。1ファイル 100MB まで。
  • 画像やファイルを見せてもらう: 「結果のグラフをチャットに表示して」と頼むと、Claude が所定の場所に置き、チャットに画像やダウンロードのリンクが出ます。3D モデル(.glb など)はタップするとビューアが開きます。

後で続きをする

  • セッションは動いたままなので、一覧から開けば続けられます。使わないものは 🗄 でアーカイブすると一覧がすっきりします(アーカイブは一覧の下の「🗄 アーカイブを開く」で見られ、📤 で戻せます)。
  • 停止: 緑の ● をタップして確認すると止まります。Claude には普段の終わり方と同じ Ctrl+C を2回送るので、会話は保存されます(裏で動いているコマンドがあれば止めます)。
  • 再開: 止まったセッションの灰色の ● (青い輪付き)をタップして確認すると、同じフォルダで続きから再開します。同じセッションがそのまま続き、それまでのチャットも残ります。シェルの中で Claude を動かしていたセッションも、Claude の続きから再開します。
  • セッションを削除しても、会話は残っています。新しく作るときに同じフォルダを選び、⏱ の欄で日時と内容の要約から選ぶと続きから再開できます。

4. 他の人と共有する

  • チャット画面の 🧑‍🤝‍🧑 を押し、相手と種類を選んで 共有する。初めは 全員・閲覧のみ になっています。
  • 閲覧のみ: 相手にはチャットのログだけが見えます。画面パネル・送信・停止はできません。全員 はこのサーバーの aigw の全ユーザーです。
  • 共同作業: 「ユーザーを指定」で名前を入れたときだけ選べます。相手もメッセージの送信・キー入力・停止ができます。ホストのシェルを共同作業で共有すると、相手はあなたの権限でコマンドを実行できます。
  • ルートのシェルは閲覧のみでしか共有できません。Email のセッションは共有できません。
  • やめるときは、パネルに並んだ相手の 解除 を押します。

人から共有されたセッションは、一覧の下の 👥 共有ログを開く に入ります(アーカイブと同じく、初めは閉じています)。開くと持ち主ごとのフォルダ(📁)が並び、フォルダを開くとその人のセッションが出ます。閲覧のみのセッションを開くと入力欄は出ず、上に「〇〇さんの共有ログ(閲覧のみ)」と出ます。

フォルダごと共有することもできます(発展編)。

送信と実行

ボタン送るもの使うとき

キーの列(ソフトキーボード)

  • ↑ ↓ ← → Tab ⇧Tab Esc ⏎(Enter)⌫ Del 🏡(Home)End PgU PgD Spc はタップするとすぐ送られます。
  • Ctrl ⇧ Alt は押しっぱなし扱いです。タップすると色が付き、次に押したキーと組み合わせて送られ、元に戻ります。Ctrl を押すと英数字のキーが現れます。

6. ターミナル画面とチャットの関係

サーバー上では、Claude やシェルは本物のターミナルの中で動いています。aigw はその様子を2つの形で見せます。

  • チャットは記録です。新しく出た出力が吹き出しとして順に積み重なり、あとで読み返したり、🧑‍🤝‍🧑 の中の 💾 で保存したりできます。
  • 画面パネルは今の画面そのものです。選択メニューの ❯ が動く、進み具合の表示が変わる、といった「その場での書き換え」はチャットには出ないので、画面パネルで見ます。
  • キーは両方に効きます。メニューが出たら画面パネルを開いて、キーの列で操作してください。
  • 画面パネルをいちばん上までスクロールすると、過去に消えていった画面を遡れます。左上の「● ライブに戻る」で今の画面に戻ります。
  • 右上の 🤖 は、Claude が裏で動かしているサブエージェントの様子です。

7. 困ったとき

症状対処
aigw にログインできない許可されたドメインのアカウントを選んでいるか確認。管理者が作ったアカウントなら、SSH で aigw-set-email を実行(1章)
SSH が繋がらない・時間切れになる・知らないホストの鍵を聞かれるSSH が内側のネットワークからだけのサーバーかもしれません。管理者が案内する方法で内側に入ってから SSH する(1章)。外から繋いで違う鍵を保存してしまったら、ssh-keygen -R <サーバー> で消す
Claude が何も返さない・ログインを求められる設定画面で、その場所の行が「Not logged in」になっていないか確認してログイン(発展編)
チャットが止まって見える🖥️ で画面パネルを開く。メニューや確認の質問で止まっていることが多いので、キーの列で答える
実行したのに Claude が動かない(入力欄に文が残っている)aigw が数秒で気づいてチャットに ⚠ を出し、30秒ごとに Enter を送り直します。受け付けられると「受け付けました」と出ます。急ぐときは、文字を入れずに 実行 を押しても同じです
画面を英語や中国語にしたい設定画面の見出しの横の選択欄で選ぶ(発展編)
キーを押しても反応が見えないチャットにはその場の書き換えが出ないため。画面パネルで確認する(6章)
Email やホストのシェルが「解錠」を求めて進まないパスキーを登録したか、その端末で登録したかを確認(発展編)。施錠中の帯が出ていればタップ
Claude の作業を止めたいEsc。セッションごと止めるなら、名前の左の緑の ● をタップして停止(会話は保存され、灰色の ● のタップで続きから再開できます)
画面が古いまま右上の ⟳ か、上のバーを下にスワイプ
セッションがどこにあるか分からないフォルダの中かもしれません。📁 の行をタップして開く。アーカイブした覚えがあれば、一覧の下の「🗄 アーカイブを開く」(発展編)
