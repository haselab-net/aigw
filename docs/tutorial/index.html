aigw チュートリアル

スマホや PC のブラウザから、サーバー上の AI エージェント(Claude Code など)を使うための手引きです。2026-10-09 時点の画面で説明します。サーバーごとに入っている機能が少し違うので、分からないところは管理者に確認してください。

aigw は https://<サーバー>/agents/ で開くチャット風の画面です。チャットに書いた指示は、サーバー上の自分専用のコンテナで動く Claude Code に届き、返事がチャットに戻ってきます。

1. アカウントを作る

管理者が許可したドメインの Google アカウントがあれば、aigw の画面から自分でアカウントを作れます(この機能を有効にしているサーバーの場合)。そうでなければ管理者に作ってもらいます。

  1. ブラウザで https://<サーバー>/agents/ を開き、「Google でログイン」から許可されたドメインのアカウントを選びます。
  2. まだアカウントが無いと「アカウント作成」のフォームが出ます。ユーザー名を決めて送信します。
    • 使える文字は英小文字・数字・-・_。先頭は英小文字か _。32文字まで。
    • あとから自分では変えられません。
  3. 送信すると SSH の秘密鍵が1回だけ表示されます。画面を閉じる前に必ず保存してください。二度と表示されません。
  4. これで aigw が使えます。次回からは Google でログインするだけです。

SSH でも入れるようにする(パスキー登録に必要)

aigw だけを使うなら SSH は不要です。ただし、Email やホストのシェルに使うパスキーの登録には SSH ログインが1回要るので、早めに済ませておくと楽です。

# 自分の PC で: もらった鍵を保存して権限を絞る
mv ~/Downloads/id_ed25519_<ユーザー名> ~/.ssh/
chmod 600 ~/.ssh/id_ed25519_<ユーザー名>

# 初回ログイン。ログイン直後にパスワードの設定を求められる
ssh -i ~/.ssh/id_ed25519_<ユーザー名> <ユーザー名>@<サーバー>

パスワードは、この初回ログインで決めるまで誰にも使えない状態になっています。2回目からは同じコマンドで入れます。

管理者に作ってもらったアカウントで aigw にログインできないときは、SSH で入って aigw-set-email you@example.com を1回実行してください。そのメールアドレスの Google アカウントでログインできるようになります。

2. 画面の見方

aigw の画面は「セッション一覧」と「チャット」の2枚です。セッションとは、サーバー上で動き続ける1つの作業場所(Claude Code やシェル)のことです。

セッションはブラウザを閉じても動き続けます。一覧から開き直せば、そのまま続きを見られます。スマホでは「ホーム画面に追加」しておくと、返事が来たときに通知が届きます(iPhone ではこれが必須です)。

3. 普段の AI コーディングのしかた

普段は Claude を選んでセッションを作り、チャットで指示するだけです。Claude は自分専用のコンテナ(砂場)の中で、ファイルを作り、コマンドを実行します。

セッションを作る

  1. 作成欄の種類で Claude を選びます。
  2. 📁 の行で作業フォルダを選びます。最初は sandhome(コンテナの中のホーム)です。
    • 「サブフォルダを開く…」で1段ずつ下へ、↑ で上へ移動します。
    • ＋ で今いる場所に新しいフォルダを作れます。
  3. ⏱ の欄は普段は「新規」のまま。前の会話を続けたいときは、ここで選びます(下の「続きから」)。
  4. 「権限確認をスキップ」は普段はオンのままでかまいません。コンテナの中なので、Claude がファイルを書き換えても外には影響しません。
  5. 名前を付けて(任意)開始を押すとチャット画面になります。

指示を出す・結果を受け取る

  • 入力欄に日本語で書いて 実行。スマホのキーボードの改行キーも実行と同じです(入力欄の中で改行したいときは Shift+Enter)。
  • Claude が考えている間も、続けて指示を送れます。
  • 手元のファイルを渡す: 📎 で選ぶか、入力欄に貼り付けます。サーバー上に保存され、そのパスが入力欄に入るので、「このファイルを見て…」と続けて送ります。1ファイル 100MB まで。
  • 画像やファイルを見せてもらう: 「結果のグラフをチャットに表示して」と頼むと、Claude が所定の場所に置き、チャットに画像やダウンロードのリンクが出ます。3D モデル(.glb など)はタップするとビューアが開きます。

後で続きをする

  • セッションは動いたままなので、一覧から開けば続けられます。使わないものは 🗄 でアーカイブすると一覧がすっきりします。
  • セッションを終了・削除しても、会話は残っています。新しく作るときに同じフォルダを選び、⏱ の欄で日時と内容の要約から選ぶと続きから再開できます。
  • Claude のセッションは claude.ai/code や Claude の公式アプリからも同じものを操作できます(画面パネルに出る /remote-control の案内)。

5. ターミナル画面とチャットの関係

サーバー上では、Claude やシェルは本物のターミナルの中で動いています。aigw はその様子を2つの形で見せます。

  • チャットは記録です。新しく出た出力が吹き出しとして順に積み重なり、あとで読み返したり、🧑‍🤝‍🧑 の中の 💾 で保存したりできます。
  • 画面パネルは今の画面そのものです。選択メニューの ❯ が動く、進み具合の表示が変わる、といった「その場での書き換え」はチャットには出ないので、画面パネルで見ます。
  • キーは両方に効きます。メニューが出たら画面パネルを開いて、キーの列で操作してください。
  • 画面パネルをいちばん上までスクロールすると、過去に消えていった画面を遡れます。左上の「● ライブに戻る」で今の画面に戻ります。
  • 右上の 🤖 は、Claude が裏で動かしているサブエージェントの様子です。

6. 砂場・ホスト・ルート・Email の違い

作成欄の種類は「どこで動くか」が違います。普段使うのは砂場(Claude・Codex・Shell (sandbox内))だけです。

種類(作成欄の表示)動く場所見えるものパスキー使いどころ
Claude / Codex / Shell (sandbox内)砂場: 自分専用のコンテナ~/sandhome だけ不要普段の開発すべて
EmailEmail の箱: 砂場とは別のコンテナ(設定されたサーバーだけ)~/mailbox だけ🔑 ホスト階層メールや個人情報など、開発用の砂場に置きたくないもの
Shell (sandbox外・ホスト)サーバーそのもの、自分の権限本物のホーム(~/)など🔑 ホスト階層コンテナの外のファイルを触るとき
Shell (root・sandbox外)サーバーそのもの、rootすべて🔓 ルート階層サーバーの管理。許可された人だけに表示
  • なぜ砂場が普段使いなのか: コンテナの中では、Claude が何を実行しても自分の ~/sandhome の外には届きません。だから権限確認をスキップしても安全です。
  • Email の箱を分ける理由: 砂場では、npm install で入ってきた他人のパッケージも動きます。メールのような情報をそこに置くと、それらからも読めてしまいます。Email の箱は砂場から見えない別のコンテナで、会話の記録も ~/mailbox の側に残ります。
  • マシン選択で ssh でつないだ他のマシンを選ぶと、その機械の Claude やシェルも使えます。砂場とはファイルを共有しません。

7. 設定画面と Claude へのログイン

Claude を初めて使う前に、使う場所ごとに1回ずつ Claude にログインします。砂場・ホスト・ルート・他のマシンでログイン情報は別々です。Email の箱だけは設定画面に行が無く、箱の中でログインします。

開き方

トップ画面のマシン選択(server の欄)で設定を選びます。戻るときは、同じ欄で server(このサーバー)を選び直します。

ログインの手順

  1. 「Accounts」の sandbox内 の行(ホストや他のマシンで使うならその行)の ログイン を押します。ログイン用のチャット画面が開きます。
  2. チャットに URL が出るので、タップしてブラウザで開き、Claude のアカウントで承認します。
  3. 表示されたコードをコピーし、チャットの入力欄に貼り付けて 実行。貼ったコードは画面に表示されませんが、それで正常です。
  4. 成功・失敗の1行が出てログイン用のセッションは自動で消えます。設定画面の行にメールアドレスが出ていれば完了です。
  • 行の文字が「Not logged in」(黄色)のところでは、その場所の Claude は動きません。
  • Codex の欄も同じ手順です(ChatGPT のアカウント)。
  • 見出しの横の ⟳ で状態を取り直せます。
  • いちばん下の Kill Chrome は、自分用のテスト用ブラウザ(ヘッドフル Chrome)を止めるボタンです。重くなったときに押してかまいません。次に使えば自動でまた起動します。

8. Email とパスキー(鍵)の登録

Email・ホスト・ルートのようにコンテナの外へ出るときは、パスキー(スマホの指紋・顔認証や PC の PIN で守られた鍵)で解錠します。aigw のログインが盗まれても、手元の端末が無ければ外には出られないようにするためです。

パスキーを登録する(最初の1回)

  1. PC から SSH でサーバーに入ります(1章)。
    ssh <ユーザー名>@<サーバー>
aigw-passkey register
  2. URL が表示されます。5分以内に、パスキーを置きたい端末(普段 aigw を使うスマホなど)のブラウザで開きます。
  3. 「パスキー登録」のページで パスキーを登録する を押し、指紋・顔認証・PIN で確認します。
  4. 完了の表示が出たら終わりです。端末を増やしたいときは、その端末でもう一度同じ手順を行います。
パスキーはサーバーごとです。別のサーバーでも使うなら、そちらでも登録します。登録済みの一覧は aigw-passkey list、今の状態は aigw-passkey status で見られます。

Email を使う

  1. 作成欄で Email を選びます(設定されたサーバーにだけあります)。フォルダは自分の ~/mailbox から始まり、Claude と同じように下のフォルダを選んだり、＋ で作ったりできます。
  2. 開始を押すと、端末のパスキーの確認が出ます。指紋などで確認すると、右上に 🔑 が付いて解錠され、セッションが始まります。
  3. 初めての Email セッションだけ、箱の中の Claude がログインを求めます。🖥️ で画面パネルを開き、キーの列の ↑ ↓ ⏎ でログイン方法(Claude のアカウント)を選び、出てきた URL を開いて承認し、表示されたコードを入力欄に貼って 実行 します。続けて権限確認をスキップしてよいかの確認が出たら、同意する方を選びます。2回目からは出ません。
  4. あとは砂場の Claude と同じ使い方です。~/mailbox は最初は空なので、使いたい道具(メールを読むスクリプトなど)は自分で、または Claude に頼んで用意します。
  • 解錠は、施錠するか2時間たつまで続きます。
  • 右上の 🔑 をタップすると、すぐに施錠できます。施錠中に Email のセッションを開くと「🔒 … 解錠する」の帯が出るので、タップして解錠します。
  • Email の箱は、砂場の Claude からは見えません。逆に、Email の中身を砂場に持ち出す指示も出さないようにしてください。

9. ルートになるための手順

ルート(サーバーの管理者権限)は、管理者が許可した人だけが使えます。経路は2つあり、どちらも本人の操作が要ります。

aigw の「Shell (root・sandbox外)」を使う

  1. 管理者に頼みます。管理者がサーバーで次を実行し、表示された URL を渡してくれます。
    sudo aigw-passkey register <ユーザー名> --tier root
  2. 受け取った URL を5分以内に、自分の端末のブラウザで開いて パスキーを登録する を押します。これがルート階層のパスキーです(ホストと Email の解錠にも使えます)。
  3. aigw を再読み込みすると、作成欄に Shell (root・sandbox外) が出ます。選んで 開始 を押し、パスキーで確認すると右上が 🔓 になり、root のシェルが開きます。
  4. root のシェルで Claude を使うには、設定画面の root の行で Claude にログインしておきます(7章)。
施錠しても、root のシェルの中の作業は止まりません。 窓が閉じると aigw から見えなくなるだけで、次に解錠すれば同じ画面に戻れます。

SSH で sudo を使う

サーバーで sudo を許可されている人は、SSH で入って sudo を使えます。誰に許可するかは管理者が決めます。

Claude が何も返さない・ログインを求められる設定画面で、その場所の行が「Not logged in」になっていないか確認してログイン(7章)
